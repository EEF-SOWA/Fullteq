Fullteq 0.9.0 beta - macOS install notes

This build is ad-hoc signed and not notarized. macOS Gatekeeper can block it.

1. Verify the ZIP against SHA256SUMS.txt.
2. Run "Install Fullteq.command".
3. If the Standalone app is blocked, right-click it and choose Open.
4. If a host refuses a plug-in, remove the quarantine attribute for that
   installed bundle only:

   xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/Fullteq.vst3"
   xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/Components/Fullteq.component"

These commands lower macOS protection for those bundles. Run them only when
the host refuses to load Fullteq and you accept that risk.

The installer uses the current user's folders. It does not use sudo.
Run "Uninstall Fullteq.command" to remove the installed items.
